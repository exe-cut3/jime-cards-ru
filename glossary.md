# Глоссарий: официальная терминология Hobby World

Источники: справочник («Vlastelin_Kolets_Spravochnik.pdf»), правила базовой игры, правила
«Тёмных троп» и «Ветра войны», сканы карт русского издания (TTS-мод 3353638862).
Термин считается подтверждённым, если встречается в этих текстах; помеченные `?` взяты из
неофициального источника (метаданные TTS-мода) и ждут проверки по картам.

Правило приоритета: текст карты > справочник > буклет правил (так написано в самом справочнике).
Пример расхождения: буклет «Тёмных троп» называет вещь Кузнеца «Молот и наковальня»,
а на карте напечатано «Молот и щипцы» — берём вариант карты.

### Формулы ключевых слов на картах (сканы русского издания)

| Ключевое слово | Пояснение в скобках на карте |
|---|---|
| Удар X | (когда вы атакуете, сбросьте эту карту, чтобы добавить X попадания к этой атаке) |
| Защита X | (сбросьте эту карту, чтобы заблокировать X урона или страха, наносимые герою в вашей области) |
| Рывок X | (во время своего хода сбросьте эту карту, чтобы переместиться на X область) |
| Отдых X | (сбросьте эту карту в конце хода, чтобы сбросить X лежащие взакрытую карты урона или страха) |
| Укрытие | (после того как вы провели проверку, сбросьте эту карту, чтобы получить карту «Скрытность») |

Другие устойчивые обороты со сканов: «Держите эту карту в открытую в своей игровой зоне»
(Keep this card faceup), «Затем переверните эту карту урона лицевой стороной вниз»
(Then flip this card facedown), «получите N {урона} взакрытую» (suffer N facedown damage),
«израсходовать эту вещь» (deplete this item), «провести проверку X вместо первоначальной
характеристики» (test X instead), «(Ограничение: 1 раз за проверку.)» (Limit once per test),
«убрать эту карту из приключения» (remove this skill from the adventure), «неактивный враг»
(exhausted enemy), «пересечённая местность» (difficult ground), «укрепления» (fortified).

Карты фигурочных паков (Злодеи Эриадора, Обитатели тьмы, Бич пустошей) переводил другой
переводчик: там «предмет» и «безделушка» вместо «вещь», «удары» вместо «попаданий», «навык»
вместо «карта», «Скрыться» вместо «Укрытие». В базе оставлено как на картах.
